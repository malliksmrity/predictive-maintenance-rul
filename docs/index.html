Predictive maintenance · aircraft engines

A simple model guesses how many flights an engine has left, give or take about 19

On 100 engines it had never seen, the typical error was about 19 operating cycles (RMSE). A model that always guesses the average is off by about 53.

Data: NASA turbofan simulation (C-MAPSS FD001). These are simulated engines, not real aircraft.

What the numbers show

How it works

  1. Each simulated engine runs until it fails, so for every past cycle we know how many cycles were left.
  2. The model learns the link between sensor readings (temperature, pressure, speed) and the cycles left.
  3. It is then tested on 100 other engines that stop before failure, with the true answer kept secret until scoring.

Limits

  • The data is simulated and has one fault type and one operating condition. Real fleets are messier.
  • The original notebook score (35.8) came from a random row split, where readings of the same engine sit in both train and test. It is slightly optimistic against 38.2 with whole engines held out.
  • The best score (about 19) uses a common trick: training labels are capped at 125 cycles, because an engine far from failure looks the same as a healthy one. This choice was compared on the same 100 test engines used for the final score, so treat it as indicative.
  • Not for real maintenance decisions.
